### AMIS1003 Introduction to Cybersecurity
Introduction to Ransomware: Threats, Vectors, and Prevention

An analytical cybersecurity research project exploring the mechanics, vectors, and defense strategies surrounding modern ransomware attacks.

### Overview
This project investigates the evolution of ransomware from early malicious software to advanced threats like Ransomware-as-a-Service (RaaS) and double-extortion schemes. It examines vulnerabilities in modern communication channels and provides practical countermeasures for organizations and individuals.

### Key Topics Covered
* **Attack Vectors:** How ransomware spreads via phishing emails, file sharing on communication tools (e.g., Teams/WhatsApp), unpatched software, and exposed RDP ports.
* **Threat Evolution:** Historical overview and modern developments, including WannaCry, Conti, and RaaS platforms.
* **Defense & Countermeasures:** Proactive strategies such as immutable/offline backups, network segmentation, automated patch management, and Multi-Factor Authentication (MFA).
